ماسح الورق - نسخة Offline بالكامل (المعالجة بتتم على الموبايل نفسه بـ OpenCV.js، والتخزين IndexedDB)
مفيش سيرفر ولا Django ولا npm للتشغيل. كل الملفات في مجلد www

== الطريقة 1: تطبيق مثبّت (PWA) - الأسهل ==
ارفع محتويات مجلد www على استضافة ثابتة مجانية بـ HTTPS (GitHub Pages أو Netlify Drop أو Cloudflare Pages).
افتح الرابط من Chrome على الموبايل مرة واحدة (بيحمّل ~13MB)، ثم القائمة ⋮ ← "تثبيت التطبيق".
بعدها بيشتغل بدون إنترنت خالص.

== الطريقة 2: ملف APK من غير Android Studio ==
1) اعمل مستودع على GitHub وارفع كل محتويات هذا المجلد (مش www بس).
2) من تبويب Actions شغّل "Build APK" (أو اعمل push على main) وانتظر ~5 دقايق.
3) نزّل ملف scanner-apk (app-debug.apk) من نتيجة التشغيل، ونزّله على الموبايل وثبّته (فعّل "تثبيت من مصادر غير معروفة").

== تجربة سريعة على الكمبيوتر ==
cd www && python -m http.server 8000   ثم افتح http://localhost:8000
(الصور والمستندات بتتخزن في المتصفح/التطبيق نفسه - لو مسحت بيانات التطبيق هتروح، صدّر PDF للمهم)
